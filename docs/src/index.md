# tm-builder

tm-builder is a YAML-based workbench for defining and running deterministic and
nondeterministic Turing machines. Use the [command reference](tm-builder/commands.md)
for setup and exports, or start with [machine definitions](tm-builder/machines.md).

The repository contains bundled teaching examples under `data/examples/`.
`make setup` copies them into the `TM Builder` folder inside the system Documents folder.
Edits in that workspace are kept separate from the application repository and
can be shared with Git.
