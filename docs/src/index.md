# tm-builder

tm-builder is a YAML-based workbench for defining and running deterministic and
nondeterministic Turing machines.

| Chapter | What it explains |
| --- | --- |
| [Commands](tm-builder/commands.md) | Setup, Windows, run, and export |
| [Viewer](tm-builder/viewer.md) | Graph editing, playback, and step limits |
| [Machine definitions](tm-builder/machines.md) | YAML fields, inputs, and bundled examples |
